# 兑换站几何模型与尺寸规格

> 最近更新：2026-04-14  
> 本文档记录RoboMaster兑换站的详细几何尺寸，用于视觉定位算法的3D模型构建

---

## 1. 整体结构

兑换站是一个**中空正方体框架**，四个角上安装有**L型红色发光灯条**作为视觉标记。

### 1.1 外形尺寸
- **正面尺寸**：288mm × 288mm（正方形）
- **深度**：212mm
- **中空区域**：240mm × 240mm（正面中心镂空）
- **框架宽度**：(288 - 240) / 2 = 24mm

### 1.2 坐标系定义（待确认）
- **原点**：兑换站几何中心
- **X轴**：水平向右
- **Y轴**：竖直向上
- **Z轴**：垂直正面向外（右手坐标系）

---

## 2. 正面L型灯条（4个）

正面有4个L型灯条，分布在四个角上，位于**外边缘与中空区域之间**。

### 2.1 标准L型灯条（3个）
位置：左上角、左下角、右下角

#### 几何结构
- **外轮廓尺寸**：50mm × 50mm
- **内轮廓尺寸**：39mm × 39mm
- **灯条宽度**：11mm（外轮廓到内轮廓的距离）
- **形状**：90度直角L型
- **边数**：6条边（封闭图形）

#### 链码描述（以左上角为例）

**坐标系定义**：
- 0 = 右方向
- 2 = 上方向
- 4 = 左方向
- 6 = 下方向
- 逆时针增大

**链码序列**：从最外面的拐点开始，顺时针遍历
```
[0, 6, 4, 6, 4, 2]
```

**说明**：
- 链码方向标准：逆时针增大（0右, 2上, 4左, 6下）
- 轮廓遍历方向：顺时针（OpenCV外轮廓标准）
- 归一化后遍历方向不影响匹配

**对应边长**：
```
[50mm, 11mm, 39mm, 39mm, 11mm, 50mm]
```

**详细描述**：
1. 边1 (方向0, 右): 50mm - 外轮廓横边
2. 边2 (方向6, 下): 11mm - 灯条宽度
3. 边3 (方向4, 左): 39mm - 内轮廓横边
4. 边4 (方向6, 下): 39mm - 内轮廓竖边
5. 边5 (方向4, 左): 11mm - 灯条宽度
6. 边6 (方向2, 上): 50mm - 外轮廓竖边

#### 角点数量
- **总计**：6个角点（对应6条边的连接点）

### 2.2 特殊L型灯条（1个）
位置：右上角（被截断设计）

#### 外轮廓
- **基础尺寸**：29mm × 29mm（L型主体）
- **截断区域**：29mm - 39mm区间为空（无灯条）
- **延伸部分**：39mm - 50mm有一个小正方形（两条边都有）
- **总长度**：50mm（与标准灯条对齐）

#### 内轮廓
- **基础尺寸**：18mm × 18mm（L型主体）
- **截断区域**：对应外轮廓，18mm - 28mm区间为空
- **延伸部分**：28mm - 39mm有小正方形

#### 灯条宽度
- **宽度**：11mm（与标准灯条一致）

#### 结构说明
```
标准L型（左上角示例）：
从最外拐点开始，顺时针遍历

边编号,长度 (mm),方向 (顺时针),坐标变化趋势
边 1,50,右 (0),"(+50,0)"
边 2,11,下 (6),"(0,−11)"
边 3,39,左 (4),"(−39,0)"
边 4,39,下 (6),"(0,−39)"
边 5,11,左 (4),"(−11,0)"
边 6,50,上 (2),"(0,+50)"

链码: [0, 6, 4, 6, 4, 2]
边长: [50, 11, 39, 39, 11, 50] (单位: mm)
6个角点: P1→P2→P3→P4→P5→P6→P1 (顺时针)
灯条宽度: 11mm
```

**其他角落的链码**：
- 左下角、右下角：链码序列会因旋转而不同，但归一化后等价
- 右上角：特殊截断型（见2.2节）

特殊L型（右上角）：
外轮廓     ┌──┐ 小正方形(39-50mm)
    29mm   │  │
       ┌───┘  │
       │ 空白 │ (29-39mm)
       │      │
       └──────┘
       └──┐ 小正方形
          │
          └──┘
```

### 2.3 安装位置
- **位置**：正面四个角，位于外边缘(288mm)与中空区域(240mm)之间
- **中心距边缘**：约 24mm / 2 + 灯条中心偏移
- **L型开口方向**：
  - 左上角：开口朝右下
  - 右上角：开口朝左下（特殊截断）
  - 左下角：开口朝右上
  - 右下角：开口朝左上

## 3. 侧面L型灯条（2个）

侧面（左右两侧）各有1个L型灯条，角度为90度。

### 3.1 尺寸
- **外轮廓长度**：230mm（单边）
- **灯条宽度**：10mm
- **内轮廓长度**：230 - 2×10 = 210mm（推测）
- **形状**：90度直角L型

### 3.2 安装位置
- **位置**：侧面边缘
- **方向**：沿侧面边缘，90度拐角
- **数量**：左右两侧各1个

### 3.3 与正面的关系
- 侧面灯条与正面灯条在立方体的棱上相连
- 可用于侧视角度的定位

## 4. 3D模型关键点坐标

### 4.1 坐标系定义
以兑换站几何中心为原点：
- **X轴**：水平向右（正面视角）
- **Y轴**：竖直向上
- **Z轴**：垂直正面向外

### 4.2 正面标准L型灯条角点（以左上角为例）

假设灯条中心位于框架中间（外边缘与中空区域中点）：
- 框架外边缘：X = -144mm, Y = 144mm
- 中空区域边缘：X = -120mm, Y = 120mm
- 灯条中心线：X = -132mm, Y = 132mm

#### 外轮廓3个角点（左上角灯条）
```
P1_outer: (-157, 157, 0)  // 左上端点
P2_outer: (-157, 132, 0)  // 拐角点（外侧）
P3_outer: (-132, 132, 0)  // 右端点
P4_outer: (-132, 157, 0)  // 上端点
```

#### 内轮廓3个角点（左上角灯条）
```
P1_inner: (-151.5, 151.5, 0)  // 左上端点
P2_inner: (-151.5, 132, 0)    // 拐角点（内侧）
P3_inner: (-132, 132, 0)      // 右端点
P4_inner: (-132, 151.5, 0)    // 上端点
```

**注**：以上坐标为初步估算，需根据实际安装位置精确测量。

### 4.3 其他角落灯条
- **右上角**（特殊截断）：需单独建模
- **左下角**：左上角镜像（Y轴翻转）
- **右下角**：左上角镜像（X、Y轴都翻转）

### 4.4 侧面灯条角点
侧面灯条沿Z轴延伸，需要3D坐标：
```
左侧面灯条（示例）：
P1: (-144, 144, 0)      // 前上角
P2: (-144, 144, -212)   // 后上角（拐角）
P3: (-144, -144, -212)  // 后下角
```

## 5. 视觉识别策略

### 5.1 正面识别（4个L型灯条）
- **可见灯条**：4个
- **特征点**：最多 4 × 6 = 24个角点
- **识别难点**：
  - 右上角特殊截断灯条需单独处理
  - 需区分内外轮廓
  - 需匹配灯条到具体位置（左上/右上/左下/右下）

### 5.2 侧面识别（1-2个L型灯条）
- **可见灯条**：1个（单侧）或2个（斜视角）
- **特征点**：6-12个角点
- **识别难点**：
  - 侧面灯条尺寸与正面不同
  - 透视变形较大

### 5.3 链码特征
根据实际测试数据：
- **正面L型灯条**：链码跳变次数 20-60次
- **倾斜视角**：链码跳变次数 100-250次
- **侧面L型灯条**：链码跳变次数 20-250次

建议链码参数：
```yaml
min_chain_code_transitions: 15
max_chain_code_transitions: 300
```

## 6. 位姿解算方案

### 6.1 方案A：单L型灯条定位
- **输入**：单个L型灯条的6个角点（或选择其中4个）
- **3D模型**：该灯条在物料框坐标系下的3D坐标
- **PnP求解**：图像角点 ↔ 3D模型点
- **输出**：物料框中心位姿

### 6.2 方案B：多L型灯条融合定位（推荐）
- **输入**：所有可见L型灯条的角点
- **3D模型**：完整物料框模型（所有灯条位置）
- **PnP求解**：基于所有特征点的全局优化
- **输出**：物料框中心位姿（精度更高）

### 6.3 鲁棒性策略
- **最小可行**：至少识别1个完整L型灯条
- **标准配置**：识别2-3个L型灯条
- **最优配置**：识别全部4个L型灯条（正面）
